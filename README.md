# Molly the Poly — animacja ekranu

[Pobierz GIF](https://github.com/Korkapetl6/ModelC/raw/refs/heads/molly-screen/Molly-the-Poly-screen.gif)

Sam ekran z orbitującymi planetami i napisem Pad. 512 × 256 px, 900 klatek, pętla 60 sekund, bez dźwięku.

Animacja odtworzona na podstawie funkcji rysowania i ruchu z [Molly the Poly autorstwa Mark Eats](https://github.com/markwheeler/molly_the_poly), commit `76cd4dc86f043546e3525c58e09eba688696172c`. To render z kodu, nie nagranie sprzętu norns. Font i rasteryzacja są przybliżone; pozycje początkowe oraz prędkości dobrano, aby pętla była płynna.

`render.py` zawiera adaptację dla Pillow, przygotowaną 2026-10-20. Licencja GPLv3, pełny tekst w LICENSE.md. Wymaga Python 3, Pillow i fontu DejaVu Sans (ścieżkę fontu można zmienić w skrypcie).
