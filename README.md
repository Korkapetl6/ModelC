# ModelC — eksperymentalny firmware NEW15

Ta gałąź zawiera gotowy plik SYX i jego kopię w archiwum ZIP, przygotowane do pobrania.

**Prototyp nie był uruchamiany ani testowany na fizycznym Elektron Model:Cycles.**
Testy programowe i integralności SYX nie potwierdzają poprawnego działania na urządzeniu.

## Pobieranie

- [ModelC-prototype.syx](firmware/ModelC-prototype.syx)
- [ModelC-prototype.zip](firmware/ModelC-prototype.zip) — po pobraniu rozpakuj plik SYX.
- [Sumy kontrolne SHA256](firmware/SHA256SUMS.txt)

Otwórz wybrany plik na GitHubie i wybierz „Download raw file”.

Prototyp powstał na bazie dostarczonego przez użytkownika NEW15. Zawiera eksperymentalne silniki Chord Beads WT i Rings Modal, generator progresji Morph oraz losowy Strum.
